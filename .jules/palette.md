## 2024-09-11 - Add loading spinner to async submit buttons
**Learning:** For asynchronous action buttons in Material UI (e.g., Save, Delete, Create), indicate the loading state visually by passing `<CircularProgress size={20} color="inherit" />` to the button's `startIcon` property while disabling the button. This prevents users from clicking multiple times and provides better feedback.
**Action:** When working on async UI interactions with MUI Buttons, add a loading spinner to the `startIcon` property when the action is loading.
